Sistema de Gerenciamento de Produtos

Este repositório apresenta um projeto desenvolvido em Java com Spring Boot, voltado para o cadastro e gerenciamento de produtos. A ideia do projeto é facilitar o controle e a organização de produtos, permitindo realizar operações como cadastrar novos produtos, listar os produtos existentes, consultar informações, atualizar dados e excluir produtos. Esse sistema pode servir como base para diferentes tipos de estabelecimentos comerciais, trazendo mais praticidade na hora de organizar e gerenciar seus produtos. Pode ser utilizado como referência para lojas de conveniência, supermercados, bombonieres, lojas de perfumes, lojas de videogames e diversos outros segmentos.

O objetivo é desenvolver uma aplicação simples e funcional, que possa ser aprimorada e adaptada de acordo com a necessidade de cada estabelecimento.

Funcionalidades:

Cadastrar produtos.

Listar produtos cadastrados.

Consultar produtos pelo ID.

Atualizar informações dos produtos.

Deletar produtos.

Tecnologias utilizadas:

Java

Spring Boot

Maven
